# Shared resources

Place approved public documents in this directory, then add an item to the relevant collection in `_data/resources.yml`:

```yaml
items:
  - title: Course notes title
    description: A short description of the course and topics.
    url: /assets/resources/your-file.pdf
```

Only list a download after its file exists. Empty collections show an “On the way” message. External URLs are also supported. Review application materials for personal information before sharing.

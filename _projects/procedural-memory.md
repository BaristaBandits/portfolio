## A more compact procedural memory

Language agents can accumulate trajectories, scripts, and task-specific skills as they interact with an environment. This work explores a workflow-centric alternative: continually consolidate repeated experience into a bounded collection of natural-language workflows.

The workflows are merged online under outcome-conditioned update policies. On ALFWorld and ScienceWorld, the framework is competitive with trajectory-level procedural memory on task success while using **3.5× fewer memory tokens on average**, with a range of 1.1–9.1× across settings.

The work studies memory representation as a design choice alongside construction, retrieval, and updating.
